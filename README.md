# Streamix — Netflix Clone UI

A responsive streaming-platform front-end demo built with **HTML5, CSS3, and vanilla JavaScript**.

## Features
- Responsive landing page with featured hero section
- Trending and popular movie rows
- Search by movie title or genre
- Genre filters (Action, Drama, Sci-Fi)
- Movie detail modal
- Add/remove titles from My List
- My List saved in `localStorage`

## Run locally
1. Extract the project folder.
2. Open `index.html` in your browser.
3. For a local development server, use the VS Code **Live Server** extension.

## Project structure

netflix-clone/

## Notes
- This is a front-end learning/demo project, not an official Netflix product.
- Poster images are loaded from TMDB image URLs and Google Fonts is used for typography, so an internet connection is required for those assets.
- The Play button is a demo placeholder; connect a licensed video source to implement playback.
